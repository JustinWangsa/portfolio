# Portfolio Website

A modern personal portfolio built with **Vite**, **Tailwind CSS**, and **React**. It showcases my skills, projects, and contact info with a sleek, responsive design.

## 🚀 Live Demo

[live demo](https://justinwangsa.vercel.app/)

## 🧠 About

This is my personal portfolio where I present my work, projects, and experience. Built with Vite for fast development and Tailwind CSS for modern styling.  

## 🛠 Built With

- [Vite](https://vitejs.dev/) – Fast frontend tooling  
- [React](https://reactjs.org/) – UI library  
- [Tailwind CSS](https://tailwindcss.com/) – Utility-first CSS framework  
- JavaScript / JSX  

## 📂 Features

- Responsive, mobile-friendly layout  
- Smooth scrolling and animations  
- Highlight projects with live links  
- Easy to customise with Tailwind classes  

## 🧩 Getting Started

To run locally:

1. Clone the repo

   ```bash
   git clone https://github.com/JustinWangsa/portfolio.git

2. Install dependencies

   ```bash
   cd portfolio
   npm install
  
3. Start the development server
    ```bash
    npm run dev
    
4. Open the URL provided in the terminal (usually http://localhost:5173)
